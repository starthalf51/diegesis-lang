기준: **확정** = 서로 부딪히는 두 곳을 원문에서 짚을 수 있고 해석으로 설명되지 않음 / **경계** = 설명 가능(짐작·회상·인물의 거짓말·직책으로 신원이 정해짐)이라 세지 않음 / **기각** = 재설정과 무관한 옛 문제(원본 run3 에 이미 있음)이거나 모순이 아님.
