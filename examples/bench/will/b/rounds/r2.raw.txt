# 셋째 항아리: 등장인물과 선언

할머니 최순례의 사십구재 전날, 시골집에 모인 세 남매와 큰고모 정숙. 장독대 셋째 항아리에 든 편지 한 통.

```sl

  unit day
  start 2026-09-13
  name ko "셋째 항아리"

character daon "김다온" major
  name ko "김다온"
  believes grandma_died

  name ko "김도현"
  believes grandma_died
  believes sell_house

  believes grandma_died

  name ko "김정숙"
  believes grandma_died
  believes jeongsuk_absent
  believes ring_taken
  believes daon_birth
  believes raised_by_jeongho
  believes not ring_entrusted

  name ko "윤말순"
  believes grandma_died

  believes ring_for_daon

place yard "마당"
  name ko "시골집 마당"

  name ko "시골집 부엌"

  name ko "뒤꼍 장독대"

  name ko "시골집 안방"
place maru "대청마루"
  name ko "시골집 대청마루"

  name ko "청련사 법당"

  name ko "할머니의 옥가락지"

  name ko "장독대 셋째 항아리"

attr ring.material = "옥"
attr jar.at = jangdok
attr jar.order = "왼쪽에서 셋째"

fact grandma_died "할머니 최순례는 구월 열나흘 새벽에 돌아가셨다" true
fact ring_entrusted "할머니는 돌아가시기 전날 큰고모 정숙에게 옥가락지를 맡겼다" false
fact jeongsuk_absent "할머니가 돌아가시기 전날인 구월 열사흘, 정숙은 서울에 있었다" true
fact letter_date "셋째 항아리에 든 편지의 날짜는 구월 열사흘이다" true
fact ring_for_daon "할머니는 옥가락지를 다온에게 물려주려 했다" true
fact open_together "속봉투는 정숙이 다온 앞에서 열어야 한다" true
fact daon_birth "다온은 정숙이 낳은 딸이다" true
fact raised_by_jeongho "다온은 정숙의 동생 정호 부부의 딸로 호적에 올라 자랐다" true
fact ring_taken "정숙은 할머니가 돌아가신 다음 날 장롱 서랍에서 옥가락지를 꺼내 갔다" true
fact jar_hint "할머니는 셋째 항아리를 사십구재 전날에 열어 보라고 일렀다" true
fact grandma_wrote "할머니는 돌아가시기 전날 마루에 앉아 편지를 쓰고 있었다" true
fact sell_house "도현은 사십구재가 끝나면 시골집을 내놓을 생각이다" true

artifact grandma_letter "할머니의 편지"
  name ko "할머니의 편지"
  contains letter_date, jeongsuk_absent, ring_for_daon, open_together
  "구월 열사흘. 오늘 정숙이는 서울 가고 집에 나 혼자다."
artifact inner_letter "속봉투"
  name ko "정숙에게 쓴 속봉투"
  contains daon_birth, raised_by_jeongho
  "정숙아, 이제는 네 입으로 말해 주어라."
```

# 무대 밖 사건

```sl
event letter_day "할머니가 편지를 쓴 날"
  when at 2026-09-13 noon
  attr jeongsuk.whereabouts = "서울"
  sunrye writes grandma_letter
  sunrye writes inner_letter
  malsun sees grandma_wrote
  sunrye tells malsun: jar_hint "셋째 항아리는 사십구재 전날에나 열어 보라고 애들한테 꼭 일러 주게."

event grandma_death "할머니가 돌아가신 새벽"
  when at 2026-09-14 dawn
  dies sunrye

event ring_taken_day "정숙이 반지를 꺼낸 날"
  when at 2026-09-15 morning
  jeongsuk does take ring
```
=== FILE: scenes/s1.dieg.md ===
---
module: thirdjar.scenes
import: thirdjar.cast
scene: s1
location: yard
date: 2026-10-31
time: evening
pov: daon
render:
  pace: slow
  tension: 0.4
mode: authored
---

```sl
lasts 20m..40m
withhold daon_birth until s5
withhold raised_by_jeongho until s5
enter jeongsuk
enter dohyun, sua, daon
jeongsuk says daon, sua, dohyun: "먼 길 왔다. 내일이 벌써 칠칠재구나."
dohyun says sua: sell_house "재 끝나면 이 집은 내놓을 거다."
sua asks jeongsuk: "할머니 반지는 어디 갔어요? 장롱 서랍이 비어 있던데요."
jeongsuk shows ring
jeongsuk lies daon, sua, dohyun: ring_entrusted "어머니가 돌아가시기 전날, 이걸 나한테 맡기셨다."
daon believes ring_entrusted
daon says jeongsuk: ring_entrusted "할머니가 고모한테 맡기셨으면 그게 맞겠죠."
sua doubts ring_entrusted
sua thinks: "고모 목소리가 너무 매끄럽다. 꼭 외워 둔 말 같다."
setup ring_home promise: ring_for_daon
jeongsuk thinks: "이 반지만은 내 손으로 지켜야 한다."
exit all
```
