# readcheck

Model-reader gate (`tools/readcheck`). Per episode, with fixed thresholds: `error` <= 2 (user decision 2026-11-13), `term` == 0, `repeat` == 0, `dump` <= 1, `flat` <= 1, and the episode wins at least 1 of 2 order-swapped pairwise comparisons against the reference (default `ref-dongbaek.txt`; `--ref` per work). Kinds are error|open|term|repeat|dump|flat|vocab|artifact. `open` (unanswered question or momentary ambiguity), `vocab` and `artifact` are recorded only; `continue` is recorded only. Call budget defaults to files x 3 (a retry on unparsable JSON counts); an episode that cannot start within the budget is `SKIPPED(budget)`; any non-PASS makes the exit code 1. Raw responses are saved as `<file>.readcheck.json`.

Cumulative reader: episode N is judged by a reader who has read 1..N-1. `dieg reader-state <work|dir> --until <scene>` writes what the reader was given before that scene (explained terms, characters seen, disclosed facts); `readcheck` picks up `<episode>.state.txt` beside each episode (or one file via `--state`) and prepends it to the reader prompt. Without a state file the episode is read cold. `repeat` = re-explaining what the state already says; `dump` = definition sentences, info-dumps, on-the-nose dialogue; `flat` = no reaction after a key event. The prompt wording is medium- and genre-neutral.

`ref-dongbaek.txt`: first ~2,100 characters of the story body of 김유정 「동백꽃」 (1936; author died 1937, public domain in Korea and the US), from `data/raw/동백꽃.txt` (ko.wikisource, fetched with `tools/fetchtext`), 3 header lines removed, the `( )` aside removed, cut at a sentence boundary. User decision 2026-11-13: reference changed to 동백꽃 (Claude's pick).

`ref-unsu.txt`: the previous reference, first ~2,000 characters of 현진건 "운수 좋은 날" (1924, public domain), from `data/raw/운수-좋은-날.txt`; kept for the record.

Orientation quiz: `go run ./tools/readcheck --orient <episode.md>` (opus, one call, one retry on unparsable output, exit 2 if still unparsable) asks a first-time reader what an opening episode taught them: name, situation, world and its rules, what the protagonist wants or fears, whether they want the next episode, and every piece of information that connected to nothing (`dangling`, quoted). The prompt is genre-neutral and asks for the answer in the text's language; "guess"/"unknown" mark what the reader could not take from the text. The answers are saved as `<episode>.orient.json`; stdout is `orient <file> dangling=<N>` followed by the name, situation, world and want lines. Recorded only: there is no pass/fail.
